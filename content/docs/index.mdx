FocalAPI 专注于创作工作流：用一个 API Key 接入图像、视频、音频、3D 与其他视觉创作模型。接口会尽量保持各模型的原生请求语义，模型可用性和价格始终以控制台模型广场为准。

## 创作能力

- **图像**：生成、编辑、多图参考与高分辨率创作
- **视频**：文生视频、图生视频、异步任务查询与成片下载
- **音频**：语音转写与文字转语音
- **3D 与视觉模型**：按控制台实际启用的模型提供
- **DeepSeek（备用）**：仅用于提示词、脚本梳理和轻量文本任务

## 基础信息

| 项目 | 值 |
| --- | --- |
| Base URL | `https://api.focalapi.com` |
| 认证方式 | `Authorization: Bearer YOUR_API_KEY` |
| 模型发现 | `GET /v1/models` |
| 价格与可用性 | 控制台模型广场 |

<Callout type="info">
FocalAPI 不将通用聊天、编码或其他文本模型作为产品主线。请先查询模型列表，再按所选创作模型的接口和参数提交任务。
</Callout>
