本章只收录 FocalAPI 对外公开的创作接口，以及 DeepSeek 的备用对话接口。上游规范中的其他端点不属于本站产品范围，不会自动出现在导航或搜索中。

## 通用约定

| 项目 | 值 |
| --- | --- |
| Base URL | `https://api.focalapi.com` |
| 认证 | `Authorization: Bearer YOUR_API_KEY` |
| 内容类型 | `application/json`；文件上传使用 `multipart/form-data` |
| 模型发现 | `GET /v1/models` |

## 接口家族

- **可用模型**：查询当前 Key 实际可调用的模型
- **图像创作**：生成和编辑图像
- **视频创作**：统一视频任务，以及 Kling、即梦等创作模型的原生任务格式
- **音频创作**：当前生产部署未启用；模型和端点重新开放后以实时目录为准
- **Gemini 图像原生接口**：用于 Gemini 图像模型的 `generateContent`
- **DeepSeek 对话（备用）**：仅用于提示词、脚本与轻量文本任务

<Callout type="info">
请求前先查询模型列表。模型的可用性、支持参数、并发和价格以控制台模型广场为准。
</Callout>
