---
title: 计费与额度
description: 创作模型的预扣、结算与用量管理
---

FocalAPI 采用预充值、按量计费。图像、视频、音频和其他视觉创作任务按所选模型的官方定价与实际请求参数结算；控制台模型广场是单价的唯一依据。

## 计费方式

| 能力 | 计费依据 |
| --- | --- |
| 图像生成与编辑 | 输出张数、尺寸、质量、参考图等模型参数 |
| 视频生成 | 时长、分辨率、模型档位与其他任务参数 |
| 音频转写与合成 | 音频时长、字符或模型的官方计费单位 |
| DeepSeek（备用） | 实际输入与输出 token 用量 |

## 预扣与结算

FocalAPI 会在提交前按照可确定的参数预扣额度，并在任务完成或响应结束后按实际结果结算差额。图像和视频任务失败时不会保留本次任务费用；最终状态以任务查询结果为准。

## 查询用量

- 控制台的日志页面：请求、模型、参数与扣费明细
- 控制台的模型广场：当前可用模型和官方单价
- 控制台的额度页面：余额、充值记录与令牌限制

<Callout type="info">
在批量生成前，先用一张图或一段短视频验证参数、质量与单价。不同模型支持的尺寸、时长和并发不同。
</Callout>
