---
title: 计费与额度
description: 额度（quota）模型、预扣与结算、用量查询与充值
---

FocalAPI 采用**预充值、按量计费**：先充值获得额度（quota），每次调用按模型价格与用量扣减。

## 计费方式

| 能力 | 计费依据 |
| --- | --- |
| 文本对话 / Embeddings / Rerank | 按 token 用量 × 模型倍率（输入、输出分别计价） |
| 图像生成 | 按张数 × 分辨率/质量系数 |
| 音频转写 / 合成 | 按音频时长或 token 用量（取决于模型） |
| 视频生成 | 按任务计费：时长、分辨率等参数决定单价 |
| 搜索 | 按调用次数 |

具体价格以控制台 **模型广场** 展示为准。

## 预扣与结算

对话类请求采用「预扣 + 结算」两阶段：

1. **预扣**：请求开始时按预估用量冻结一部分额度；
2. **结算**：响应完成后按实际 token 用量多退少补。

因此超长输出场景下，余额需高于预扣上限才能发起请求；余额不足会返回 `402`。

## 异步任务计费（视频等）

视频生成等异步任务在**创建任务时**按任务参数一次性扣费。任务失败会自动退回扣除的额度（以任务状态为准）。

## 查询用量

- 控制台 **日志** 页面：逐条调用的 token 用量与扣费明细
- 控制台 **额度** 相关页面：当前余额与充值记录

## 充值

在控制台 **充值** 页面选择金额完成支付，额度实时到账。如需对公充值或发票，请联系站点运营方。

<Callout type="info">
生产环境建议：为关键业务令牌设置独立的额度限制，并定期导出用量日志对账。
</Callout>
