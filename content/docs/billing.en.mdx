---
title: Billing and Quota
description: Pre-charge, settlement, and usage management for creative models
---

FocalAPI uses prepaid, usage-based billing. Image, video, audio, and other visual-creation tasks settle against the selected model's official price and the actual request parameters. The model catalog in the console is the single source of truth for unit prices.

## Billing basis

| Capability | Billing basis |
| --- | --- |
| Image generation and editing | Output count, size, quality, reference images, and model-specific parameters |
| Video generation | Duration, resolution, model tier, and other task parameters |
| Transcription and speech | Audio duration, characters, or the model's official billing unit |
| DeepSeek (fallback) | Actual input and output token usage |

## Pre-charge and settlement

FocalAPI pre-charges the determinable request parameters before submission, then settles the difference against the actual result when the response or task finishes. Failed image and video tasks do not retain a charge; use the task status as the final record.

## Check usage

- Console logs: request, model, parameters, and charge detail
- Model catalog: currently available models and official unit prices
- Quota pages: balance, top-ups, and token limits

<Callout type="info">
Before a batch run, validate parameters, quality, and unit price with one image or a short video. Supported sizes, duration, and concurrency differ by model.
</Callout>
