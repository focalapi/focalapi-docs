FocalAPI is a unified AI capability gateway: call mainstream LLMs and multimodal models through OpenAI-compatible APIs with a single key, pay-as-you-go.

## Capabilities

- **Chat**: OpenAI Chat Completions, Responses, Claude Messages and Gemini formats
- **Images**: OpenAI-compatible image generation and editing
- **Video**: asynchronous task APIs, Sora-compatible plus Kling and Jimeng native formats
- **Search**: web search API to ground model answers with live information
- **More**: Embeddings, Rerank, audio transcription & speech, moderation

## Essentials

| Item | Value |
| --- | --- |
| Base URL | `https://focalapi.com` |
| Authentication | `Authorization: Bearer YOUR_API_KEY` |
| Style | REST, JSON requests and responses |
| Streaming | SSE on chat endpoints (`stream: true`) |

<Callout type="info">
If you self-host FocalAPI, replace the Base URL with your own domain. Paths and parameters are identical.
</Callout>
