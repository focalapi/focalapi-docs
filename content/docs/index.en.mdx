FocalAPI is built for creative workflows: one API key for image, video, audio, 3D, and other visual-creation models. Requests preserve each model's native semantics wherever possible. The live model catalog in the console is the source of truth for availability and pricing.

## Creative capabilities

- **Images**: generation, editing, reference images, and high-resolution creation
- **Video**: text-to-video, image-to-video, asynchronous task polling, and asset download
- **Audio**: transcription and text-to-speech
- **3D and visual models**: available when enabled in the live model catalog
- **DeepSeek (fallback)**: prompt writing, outlines, and lightweight text tasks only

## Essentials

| Item | Value |
| --- | --- |
| Base URL | `https://api.focalapi.com` |
| Authentication | `Authorization: Bearer YOUR_API_KEY` |
| Model discovery | `GET /v1/models` |
| Availability and pricing | Model catalog in the console |

<Callout type="info">
FocalAPI does not position general chat, coding, or other text models as its primary product surface. List models first, then use the endpoint and parameters for the selected creative model.
</Callout>
