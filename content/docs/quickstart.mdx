---
title: 快速开始
description: 用一个创作模型完成第一次 FocalAPI 调用
---

本指南用图像生成演示 FocalAPI 的基本流程。开始前请在控制台创建 API Key，并以 `GET /v1/models` 和模型广场确认当前 Key 可用的模型。

## 1. 查询可用模型

```bash
curl https://api.focalapi.com/v1/models \
  -H "Authorization: Bearer $FOCALAPI_KEY"
```

只使用响应中存在的模型 ID。不同用户分组的可见模型、参数与价格可能不同。

## 2. 生成第一张图片

下面以 Seedream 5.0 Pro 为例；如果它不在你的模型列表中，请换成列表里的图像模型。

```bash
curl https://api.focalapi.com/v1/images/generations \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "dola-seedream-5-0-pro-260628",
    "prompt": "电影感海边灯塔，晨雾，柔和的蓝金色光线",
    "size": "2k",
    "watermark": false
  }'
```

响应会返回图像 URL 或 base64 数据，具体取决于模型与请求参数。

## 3. 创建视频任务

视频是异步任务：先创建、再轮询、最后下载成片。

```bash
curl https://api.focalapi.com/v1/video/generations \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "dreamina-seedance-2-0-mini-260615",
    "prompt": "镜头缓慢推进雨中的城市霓虹街道",
    "duration": 5,
    "size": "1280x720"
  }'
```

拿到 `task_id` 后，使用 `GET /v1/video/generations/{task_id}` 查询状态。完整流程见[视频任务指南](/docs/guides/video-tasks)。
