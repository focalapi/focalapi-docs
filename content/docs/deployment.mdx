## Docker Compose 快速部署

FocalAPI 服务端为单一 Go 二进制 + 前端静态资源，官方提供 Docker 镜像与 compose 配置：

```bash
git clone https://gitee.com/xnn-ai/focalapi-llm.git
cd focalapi-llm
docker compose up -d
```

默认使用 SQLite，开箱即用；生产环境建议切换 MySQL 或 PostgreSQL，并配置 Redis。

## 关键环境变量

| 变量 | 说明 |
| --- | --- |
| `SQL_DSN` | 主库连接串（不设置则用 SQLite） |
| `REDIS_CONN_STRING` | Redis 连接串（缓存/限流/任务状态） |
| `SESSION_SECRET` | 会话签名密钥，生产必须显式设置 |
| `FOCALAPI_ENV` | 设为 `production` 启用生产模式（强制安全 Cookie 等） |
| `CORS_ALLOWED_ORIGINS` | 跨域白名单，逗号分隔；默认仅允许同源 |

## 反向代理

站点需挂载在域名根路径（`/`）。以 Caddy 为例：

```txt
api.example.com {
    reverse_proxy 127.0.0.1:3000
}
```

## 升级

1. 备份数据库；
2. 拉取新镜像重启：`docker compose pull && docker compose up -d`；
3. 启动时自动执行数据库迁移，观察日志确认无报错。

<Callout type="warn">
升级前务必阅读发版说明中的 Breaking Changes；跨大版本升级建议先在测试环境演练。
</Callout>

更多细节见源码仓库 `deploy/` 目录与 README。
