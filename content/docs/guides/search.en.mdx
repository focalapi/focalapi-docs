`POST /v1/alpha/search` provides standalone web search with structured results, ready for retrieval-augmented generation (RAG) or fact-checking.

## Basic call

```bash
curl https://focalapi.com/v1/alpha/search \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "2026 World AI Conference dates and venue"
  }'
```

## Typical pattern: search + chat (two calls)

1. Call the search API for live results;
2. Feed the results into the chat context so the model answers with fresh information.

```python
from openai import OpenAI
import requests

KEY = "sk-..."
BASE = "https://focalapi.com"

# 1. Search
hits = requests.post(
    f"{BASE}/v1/alpha/search",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"query": "today's AI industry news"},
).json()

# 2. Chat with results in the system context
client = OpenAI(base_url=f"{BASE}/v1", api_key=KEY)
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": f"Answer based on these search results:\n{hits}"},
        {"role": "user", "content": "What happened in AI today?"},
    ],
)
print(resp.choices[0].message.content)
```
