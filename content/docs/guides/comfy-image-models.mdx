这些图像模型由 Comfy Cloud 账户池执行，但客户端不需要了解账户池或工作流。选择模型后，继续使用其官方原生的请求与响应格式。

<Callout type="info">
模型是否可调用取决于令牌分组和管理员的渠道配置；以 `GET /v1/models` 与控制台模型广场的实际结果为准。
</Callout>

## 统一图像生成接口

以下模型使用 `POST /v1/images/generations`；编辑图片时使用 `POST /v1/images/edits`。FocalAPI 会保留模型所需的创作参数语义，并统一返回图像结果。

| 模型 ID | 产品名称 |
| --- | --- |
| `gpt-image-2` | GPT Image 2 |
| `seedream-4-0-250828` | Seedream 4.0 |
| `seedream-4-5-251128` | Seedream 4.5 |
| `dola-seedream-5-0-pro-260628` | Dola Seedream 5.0 Pro |
| `seedream-5-0-260128` | Seedream 5.0（also supports `seedream-5-0-lite-260128`） |
| `grok-imagine-image-quality` | Grok Imagine Quality |
| `grok-imagine-image-pro` | Grok Imagine Pro |
| `grok-imagine-image` | Grok Imagine |

```bash
curl https://api.focalapi.com/v1/images/generations \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "dola-seedream-5-0-pro-260628",
    "prompt": "晨雾中的海边灯塔，电影感光影",
    "size": "2k",
    "watermark": false
  }'
```

`gpt-image-2` 支持 `low`、`medium`、`high` 三档 `quality`，并支持 `background` 与单图 `mask` 编辑。Seedream 各模型支持的尺寸档位不同（例如 5.0 Pro 为 `1k`/`1.5k`/`2k`）；提交前以接口返回的校验结果为准，超范围返回 400 并列出该模型支持的档位。

## Gemini 原生接口

以下模型使用 Gemini 的原生 `generateContent` 接口。生成图像时，`generationConfig.responseModalities` 推荐 `["IMAGE", "TEXT"]`（`"IMAGE"` 亦可）；带上 `TEXT` 时，问候、问答等非图像类提示词更可能被模型转换成图像输出。

| 模型 ID | 产品名称 |
| --- | --- |
| `gemini-3-pro-image-preview` | Gemini 3 Pro Image Preview |
| `gemini-3.1-flash-image-preview` | Nano Banana 2 |
| `gemini-3.1-flash-lite-image-preview` | Nano Banana 2 Lite |

```bash
curl 'https://api.focalapi.com/v1beta/models/gemini-3.1-flash-image-preview:generateContent' \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "A clean product illustration of a blue ceramic mug"}]}],
    "generationConfig": {
      "responseModalities": ["IMAGE", "TEXT"],
      "responseFormat": {
        "image": {"aspectRatio": "1:1", "imageSize": "1K"}
      }
    }
  }'
```

输出图片在响应候选项的 `inlineData` 中返回。需要指定构图或清晰度时，按 Gemini 原生字段在 `generationConfig.responseFormat.image` 中使用 `aspectRatio` 与 `imageSize`（`imageConfig` 与顶层 `aspectRatio` 不被接受）；FocalAPI 会按模型能力校验参数。

## 计费与重试

价格与请求参数相关，例如图片张数、分辨率、质量档位和参考图数量。FocalAPI 会在提交任务前预扣，并以实际成功输出的张数结算；提交失败不会保留本次请求的费用。具体单价以控制台模型广场为准。
