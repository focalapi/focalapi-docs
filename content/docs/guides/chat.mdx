---

FocalAPI 同时支持三种主流对话 API 格式，同一个密钥通用。**优先推荐 OpenAI 格式**——生态最广、SDK 最全。

## OpenAI 格式（推荐）

`POST /v1/chat/completions`，兼容 OpenAI SDK 与绝大多数第三方客户端：

```bash
curl https://focalapi.com/v1/chat/completions \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "system", "content": "你是简洁的助手"},
      {"role": "user", "content": "用一句话解释量子计算"}
    ],
    "temperature": 0.7,
    "stream": false
  }'
```

另支持 OpenAI 新一代 `POST /v1/responses` 接口（含 `/v1/responses/compact`），适合使用 Responses API 生态的应用。

## Claude 格式

`POST /v1/messages`，兼容 Anthropic Messages API，可直接对接 Claude Code 等 Claude 生态工具：

```bash
curl https://focalapi.com/v1/messages \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-sonnet-4-5",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

## Gemini 格式

`POST /v1beta/models/{model}:generateContent`，兼容 Google Gemini API：

```bash
curl "https://focalapi.com/v1beta/models/gemini-2.5-flash:generateContent" \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "你好"}]}]
  }'
```

## 通用注意事项

- **模型名**：以 `GET /v1/models` 返回的 `id` 为准
- **max_tokens**：必填上限（各格式均有服务端最大值），超出会被拒绝或截断
- **流式**：三种格式都支持流式响应，OpenAI 为 SSE `data:` 帧，Claude/Gemini 各随其协议
- **多模态输入**：图像/音频输入随模型能力而定，请求格式与官方一致
