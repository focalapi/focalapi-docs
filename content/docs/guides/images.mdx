---
title: 图像创作
description: 生成、编辑和调用创作图像模型
---

使用 `POST /v1/images/generations` 生成图像，使用 `POST /v1/images/edits` 进行编辑。不同模型支持的尺寸、参考图、质量档位与输出格式不同，提交前以模型广场和接口校验结果为准。

```bash
curl https://api.focalapi.com/v1/images/generations \
  -H "Authorization: Bearer $FOCALAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedream-5-0-260128",
    "prompt": "玻璃质感的未来运动鞋海报，干净棚拍，蓝白配色",
    "size": "2k",
    "watermark": false
  }'
```

## 参数要点

| 参数 | 说明 |
| --- | --- |
| `model` | 必填；使用 `GET /v1/models` 返回的图像模型 ID |
| `prompt` | 描述主体、构图、材质、光线与风格 |
| `size` | 分辨率档位或宽高比；支持值取决于模型（Seedream 使用官方档位如 `1k`/`2k`） |
| `quality` | 仅在模型支持时使用 |

<Callout type="info">
创作模型按照各自的原生能力校验参数。当前模型 ID、参数差异与 Gemini 原生字段见[创作图像模型](/docs/guides/comfy-image-models)。
</Callout>
