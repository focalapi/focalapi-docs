# FocalAPI documentation

The FocalAPI user documentation site is built with [Fumadocs](https://fumadocs.dev), Next.js 16, and static export. It provides Chinese and English content, while the API reference is generated from an OpenAPI specification.

- Product: [focalapi.com](https://focalapi.com)
- Source: [GitHub](https://github.com/focalapi/focalapi-docs)
- Output: a fully static `out/` directory suitable for static hosting, a VPS, Caddy, or Nginx

## Common commands

```bash
bun install          # Install dependencies.
bun run dev          # Start the local development server with hot reload.
bun run build        # Build the static site into out/.
bun run start        # Preview the generated site locally.
bun run sync:openapi # Synchronize OpenAPI from ../focalapi-llm or a supplied repository path.
bun run gen:api      # Generate API reference pages from openapi/relay.json.
bun run types:check  # Run type checking.
```

## Content structure

```text
content/docs/
├── index.mdx / index.en.mdx        # Home page: Chinese default and English translation.
├── quickstart.mdx / .en.mdx        # Quick start.
├── authentication.mdx / .en.mdx    # Authentication.
├── billing.mdx / .en.mdx           # Billing and quota.
├── guides/                          # Task-oriented guides.
│   ├── meta.json / meta.en.json    # Bilingual directory titles and ordering.
│   └── chat / images / video-tasks / search, each with an .en.mdx counterpart.
├── api/                             # Most files are generated by gen:api; do not edit them manually.
│   ├── index.mdx                   # Handwritten API-reference landing page.
│   └── <group>/<operation>.mdx     # Generated endpoint pages.
├── deployment.mdx / .en.mdx        # Operations and deployment.
└── errors.mdx / .en.mdx            # Error codes.
```

### Localization conventions

- Simplified Chinese is the default: `page.mdx`. English translations use `page.en.mdx` in the same directory.
- Directory titles and ordering use `meta.json` for Chinese and `meta.en.json` for English.
- When an English page is absent, the English site falls back to the Chinese source.
- The language switcher and UI text, including OpenAPI components, use the official Simplified Chinese package from `@fumadocs/language`.

## OpenAPI synchronization workflow

The canonical source for generated API reference pages is `docs/openapi/relay.json` in focalapi-llm:

```bash
bun run sync:openapi # Copy the specification and inject the focalapi.com server.
bun run gen:api      # Regenerate content/docs/api/ endpoint pages and meta.json.
bun run build        # Validate the bilingual static export.
```

Important rules:

- **Do not edit** `content/docs/api/<group>/*.mdx` manually. Generated files include a marker and will be overwritten.
- `content/docs/api/index.mdx` is handwritten and is not touched by the generator.
- Group directory names and labels are maintained in the `groups` map in `scripts/generate-docs.ts`.
- Add every new upstream tag to that map; otherwise it falls into `misc`.
- The upstream specification may contain duplicate `operationId` values such as `createImage`. The generator adds numeric suffixes to avoid filename collisions. The durable fix is to give upstream operations unique IDs.

## Deployment

### Production Docker deployment with focalapi-llm

The current release flow builds the image on the server. The local machine only archives and uploads a verified commit. Validate and push the target commit to `origin` first:

```bash
bun run types:check
bun run build
./deploy/deploy-docs-server.sh [commit]
```

The script verifies that the commit is pushed, archives and uploads source, builds the `linux/amd64` image, updates the `docs` service in the focalapi-llm Compose project, and checks `http://127.0.0.1:3001/zh/docs`.

- The Compose service is defined in `deploy/focalapi-llm/docker-compose.prod.yml` in focalapi-llm. The application configuration must be deployed at least once before the first documentation release.
- Public access requires `docs.focalapi.com` to proxy to `127.0.0.1:3001` and a matching DNS record. See the focalapi-llm deployment documentation for the Caddy example.
- The main site reads `general_setting.docs_link`, which defaults to `https://docs.focalapi.com`. Existing databases may require a one-time administrator update.
- To roll back, retag a previous `focalapi-docs:<version>` image as `focalapi-docs:latest`, then run `docker compose ... up -d docs` with the production Compose file.

### Static hosting

`bun run build` writes the complete static site to `out/`. Example Caddy configuration:

```text
docs.focalapi.com {
    root * /var/www/focalapi-docs
    file_server
    try_files {path} {path}.html {path}/index.html
}
```

- Set `metadataBase` in `src/app/layout.tsx` to the production domain before release.
- `/` redirects to `/zh` or `/en` based on browser language.
- `/docs` and `/docs/<page>` are language-neutral deep links that redirect to the matching language path. Static export implements these as client-side redirects rather than server-side 301 responses.

## Notes

- Site search is a build-time static Orama index with multilingual tokenization and requires no additional Chinese configuration.
- Code examples derive their server URL from the OpenAPI `servers` field. Server-rendered HTML may contain an `example.com` placeholder that is replaced during hydration; this is framework behavior.
- `/v1/alpha/search` is not currently included in the OpenAPI specification. Its usage is documented in the handwritten Search guide.
